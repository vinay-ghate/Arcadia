# Tic-Tac-Toe 2 Player 👥

The classic strategy game for two players! Challenge your friends in this beautifully designed version of the timeless grid game.

## 🎮 How to Play

### Objective
Be the first player to get three of your marks in a row, column, or diagonal!

### Controls
- **Click**: Place your mark on an empty cell
- **Back Button**: Return to main menu
- **Restart**: Reset the current game anytime

### Game Flow
1. **Choose Symbol**: First player picks X or O (X always goes first)
2. **Take Turns**: Players alternate placing marks
3. **Win or Draw**: First to three in a row wins, or draw if board fills
4. **Play Again**: Continue for multiple rounds

## 🎯 Game Rules

### Basic Rules
- **Turn Order**: X always goes first
- **Valid Moves**: Only empty cells can be selected
- **Winning**: Three marks in a row, column, or diagonal
- **Draw**: All cells filled with no winner

### Scoring
- **X Wins**: Tracked in left score box
- **Draws**: Tracked in middle score box  
- **O Wins**: Tracked in right score box
- **Running Total**: Scores persist across rounds

## 💡 Strategy Guide

### Opening Moves
- **Center Control**: Middle square offers most winning opportunities
- **Corner Start**: Corners provide strong strategic positions
- **Edge Caution**: Edge squares offer fewer winning paths

### Advanced Tactics
- **Fork Creation**: Set up two winning threats simultaneously
- **Block and Build**: Prevent opponent wins while creating your own
- **Pattern Recognition**: Learn common winning combinations

### Psychological Play
- **Tempo Control**: Vary your thinking time to keep opponent guessing
- **Misdirection**: Make moves that seem defensive but set up attacks
- **Pressure Points**: Force opponent into difficult decisions
